# CLAUDE.md — MaxTubeStream

## Project Overview

MaxTubeStream is a **Max/MSP patch** that streams YouTube videos using **Node for Max** and **yt-dlp**. It fetches direct MP4 stream URLs from YouTube links and sends them to a `jit.movie~` object for real-time video playback inside Max.

- **Author:** POHAO CHI
- **License:** MIT
- **Language:** JavaScript (Node.js, CommonJS)
- **Runtime:** Node for Max (bundled with Max 8+)

## Key Technical Details

### watch-youtube.js

- Uses `require("max-api")` — the Node for Max bridge API. This module is provided by the Max runtime and is **not** an npm dependency.
- Uses `child_process.exec` to shell out to `yt-dlp`.
- The `yt-dlp` binary path is hardcoded to `/usr/local/bin/yt-dlp`. Users on other systems may need to adjust this.
- Exposes a single Max handler `open` that accepts a YouTube URL.
- Outputs via `maxApi.outlet()`:
  - `combined_url <URL>` — when yt-dlp returns a single combined stream.
  - `video_url <URL>` + `audio_url <URL>` — when yt-dlp returns separate streams.
- Comments in the source are written in **Traditional Chinese (繁體中文)**.

### Max Patch (watch-youtube.maxpat)

- Binary/JSON file generated by Max. Do not hand-edit.
- Routes the script's outlet messages to `jit.movie~` for playback.

### Dependencies

- **Runtime:** No npm runtime dependencies (empty `dependencies` in package.json). The only require'd module (`max-api`) is provided by the Max environment.
- **External tool:** `yt-dlp` must be installed on the system and accessible at the hardcoded path or in `PATH`.

## Conventions & Guidelines

1. **Keep it simple.** This is a small single-file utility. Avoid over-engineering.
2. **CommonJS modules.** Use `require()` / `module.exports`, not ES module syntax — Node for Max expects CommonJS.
3. **No runtime npm dependencies.** The `max-api` module comes from Max itself. Only add npm packages if truly necessary.
4. **Comments in Traditional Chinese** are acceptable and match the author's convention.
5. **yt-dlp flags:** The current format selector is `-f best[ext=mp4]`. Changing this affects which stream URLs are returned (single combined vs. separate video+audio).
6. **Security:** The script passes a URL to a shell command via `exec()`. Any changes should be careful to avoid command injection (the current code wraps the URL in double quotes, but does not sanitize it further).
7. **Max patch edits** should be done inside the Max application, not by hand-editing the `.maxpat` JSON.
